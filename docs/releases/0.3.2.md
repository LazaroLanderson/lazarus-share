# Lazarus Share 0.3.2 — Correção de Convites pelo Navegador e Ativação Instantânea

Esta versão corrige a abertura de salas a partir de links do navegador no Windows e Linux, elimina esperas de descompactação no executável portátil e garante que a aplicação venha para o primeiro plano ao receber convites.

## Novidades e Correções

- **Ativação Confiável pelo Navegador (Chrome/Edge/Firefox):**
  - Ajustado o link do protocolo nativo em `join.html` para incluir o token de acesso tanto no caminho (`/join/TOKEN`) quanto nos parâmetros de consulta (`?token=...`), impedindo que navegadores baseados no Chromium descartem o token ao invocar manipuladores externos de URL.
  - Flexibilização do parser `Protocol::inviteSecret` para tolerar barras finais (`/`), caminhos, queries, codificação de caracteres (`%23`) e aceitar colagem direta do código da sala (token de 26 caracteres).

- **Encaminhamento Instantâneo no Windows Portátil:**
  - O wrapper portátil `LazarusShare.exe` agora verifica se já existe uma instância do programa em execução antes de iniciar a descompactação via PowerShell.
  - Caso o aplicativo já esteja aberto, o convite é repassado diretamente via Named Pipe em menos de 10 milissegundos, abrindo a sala imediatamente sem uso desnecessário de disco ou processamento.

- **Foco e Feedback de Janela:**
  - Adicionada permissão explícita de foco (`AllowSetForegroundWindow`) e ativação direta (`SetForegroundWindow`) no Windows para que a janela venha automaticamente para frente ao clicar no link.
  - Adicionado aviso explícito em tela caso o usuário clique no link da sala em que já está conectado.

## Validação

- Testes de autenticação e protocolo (`protocol-test`) aprovados com 100% de cobertura dos novos formatos de URL.
- Testes de entrega e IPC de ativação (`activation-test`) aprovados.
- Compilação cruzada do launcher portátil Windows (`launcher.cpp`) validada com MinGW e bibliotecas estáticas.
