# Lazarus Share 0.3.5 — Integração com Bot no Discord, Anúncio por Webhook e Modo Coordenador

Esta versão adiciona suporte completo a criação e acompanhamento de salas de transmissão via Bot no Discord, integração com Webhooks diretamente no aplicativo desktop e modo coordenador no servidor de sinalização.

## Novidades e Melhorias

- **Bot no Discord (`bot/`):**
  - Comando slash `/share` (e `/lazarus`): cria automaticamente uma sala com aprovação desativada, detecta quem está na mesma chamada de voz e publica no chat um Embed com menção a todos os membros e botão interativo `[🚀 Entrar na Transmissão]`.
  - Início com 1 clique (deep link): o botão dispara `lazarus-share://join/<TOKEN>` para abrir diretamente o aplicativo sem precisar digitar código.
  - Sincronização em tempo real: o Bot acompanha eventos de transmissão via WebSocket, atualizando dinamicamente o status no Discord com o nome de quem está transmitindo ao vivo e o contador de espectadores.
  - Comando `/encerrar` e encerramento automático quando o canal de voz esvazia.
  - Empacotamento Docker pronto para deploy na VPS via Docker Compose.

- **Servidor de Sinalização v2 com Modo Coordenador (`server/service.py`):**
  - Suporte ao atributo `coordinator: true` no protocolo de criação de sala (`create`).
  - O bot mantém a sala ativa no servidor sem consumir os 5 slots de mídia P2P permitidos para participantes humanos.
  - Isola o bot de pares WebRTC (`ready`), otimizando banda e processamento do servidor.

- **Aplicativo Desktop (`app/`):**
  - Botão **"Anunciar no Discord"** adicionado ao banner da sala criada para compartilhar instantaneamente via Webhook.
  - Configuração de Webhook do Discord na tela de Configurações (`QSettings`), permitindo salvar e testar a URL de divulgação.

- **Infraestrutura e Deploy Automatizado (`infra/`):**
  - Inclusão do container `bot` em `infra/compose.single.yml` e `infra/compose.yml`.
  - Suporte a injeção do secret `DISCORD_BOT_TOKEN` diretamente pelo GitHub Actions sem exigir acesso SSH manual à VPS.
  - Documentação completa em `docs/DISCORD.md`.
